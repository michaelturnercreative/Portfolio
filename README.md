# Michael Turner Portfolio

This folder is the static website. Publish its contents with `index.html` at the site root. The active portfolio images are in `content/projects`, and `content/generated-images.js` lists the images shown in project galleries.

To preview locally on a Mac, double-click `Start Portfolio.command`. To refresh the gallery after adding or removing images, double-click `Refresh Portfolio Images.command` before uploading changes.

Unselected artwork and original production files are kept outside this folder in the sibling `Portfolio_Source_Archive` directory. They are not needed to display the website.

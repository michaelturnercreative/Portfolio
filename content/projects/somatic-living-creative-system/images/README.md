# Somatic Living image folders

Drop replacement or additional images into the section that best describes the work:

- `featured` — one strongest image used as the project cover
- `art-direction` — visual direction, mood, or campaign overview images
- `graphic-design` — social carousels, thumbnails, email, or branded graphics
- `photography` — finished photography
- `digital-web` — member dashboard, landing pages, and membership-flow screens
- `motion-video` — video stills, motion frames, or edited content
- `process` — planning, workflows, sketches, or before-and-after material

Use clear filenames because the website turns each filename into basic image-description text. Start the portfolio preview after adding images so the gallery list refreshes automatically.

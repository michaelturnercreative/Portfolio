# Add project images here

Keep project imagery organized by purpose:

- `featured` — one strong cover image that represents the entire project.
- `art-direction` — concepts, campaign worlds, moodboards, shoot direction, and finished systems.
- `graphic-design` — layouts, campaign graphics, print, email, and social design.
- `photography` — final product, on-model, editorial, and retouched photography.
- `digital-web` — landing pages, ecommerce, dashboards, mobile, and desktop screens.
- `motion-video` — thumbnails, GIFs, motion frames, and video stills.
- `process` — sketches, iterations, contact sheets, before-and-after work, and production details.

Use JPG, PNG, WebP, or GIF files. After adding them in Finder, double-click `../../../../Refresh Portfolio Images.command` to update the generated site image list.

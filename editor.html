Finder-based workflow

Drop images into folders. Refresh the site.

The project folders are now the source of truth for new imagery. Add files in Finder, then refresh the image list with the included Mac tool. No browser folder access is required.

Four simple steps

How to add work

  1. 01

    Open a project folder

    Go to content / projects and open the project you want to update.

  2. 02

    Choose an image section

    Inside images, choose Featured, Art Direction, Graphic Design, Photography, Digital & Web, Motion & Video, or Process.

  3. 03

    Drop in your images

    Use JPG, PNG, WebP, or GIF files. The first alphabetically named image in Featured becomes the project cover.

  4. 04

    Refresh the image list

    Double-click Refresh Portfolio Images.command, then refresh the portfolio in your browser.

Automatic option

Double-click Start Portfolio.command instead of the basic preview server. It watches the image folders while it runs, so newly dropped files are discovered automatically; refresh the browser to see them.
